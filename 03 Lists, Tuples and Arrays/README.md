# 03 Lists, Tuples and Arrays

## Syllabus focus

Store ordered collections and work with their elements using indexing, slicing, iteration, and built-in operations.

## Learning outcomes

- Create lists and tuples, access elements, and traverse a sequence.
- Update a list and use common operations such as `append`, `max`, and `min`.
- Explain that lists are mutable while tuples are immutable.
- Recognize the difference between Python sequences and library-backed numerical arrays.

## Programs in this folder

Seven Python files use collection-style data, including `n largest.py`, `n smallest.py`, `Book Management.py`, and `Student Grade Management.py`. The date conversion and search examples also process sequences.

No dedicated NumPy array exercise is included; NumPy and Pandas belong to Experiment 09.
