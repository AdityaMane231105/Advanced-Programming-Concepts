# 06 File and Directory Handling

## Syllabus focus

Read, write, append, search, compare, and organize data stored in files and directories.

## Learning outcomes

- Open text files in appropriate modes and close them safely.
- Read complete files, lines, words, and characters.
- Write or append output and process file contents line by line.
- Search, replace, compare, and combine text files.
- Handle paths and missing-file cases clearly.

## Programs and data in this folder

The folder has 31 files, including 25 Python programs and supporting text/data files. Examples include `Read File`, `Comparing Files`, `Merging Files`, `Find & Replace in File`, and `Word Count` exercises.

Some examples expect their data file to remain beside the program in its original subfolder. Run them from that folder when they use a relative path.
