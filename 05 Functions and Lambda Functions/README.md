# 05 Functions and Lambda Functions

## Syllabus focus

Break programs into reusable functions and understand arguments, return values, scope, recursion, and compact anonymous functions.

## Learning outcomes

- Define and call functions with parameters and return values.
- Separate a task into smaller reusable operations.
- Trace recursive calls and identify their base cases.
- Use a lambda expression for a small, single-expression function where appropriate.

## Programs in this folder

This folder contains 20 Python files, including function exercises for factorials, Fibonacci numbers, text cleanup, searching, and utility modules. Examples include `Factorial.py`, `Fibonacci.py`, and the `Number Utils`, `String Utils`, and `Recursive Utils` folders.

Review each program’s imports before running it; some examples call a helper module in the same subfolder.
