# Python and VS Code Setup

## Install Python

1. Download the current Python 3 installer from the official Python downloads page at https://www.python.org/downloads/.
2. Run the installer. On Windows, select the option to add Python to PATH if it is offered.
3. Open a new terminal and run `python --version`. If your system uses the Python launcher, run `py --version`.
4. Check pip with `python -m pip --version`.

## Configure VS Code

1. Install Visual Studio Code and the Microsoft Python extension.
2. Open the `Python_Setup_Exercises` folder.
3. Use the interpreter selector to choose the Python 3 interpreter you installed.
4. Open a `.py` file and run it from the integrated terminal with `python filename.py`.
5. Read error messages in the terminal. The line number and exception type identify where a program stopped.

The editor is where code is written. The selected Python interpreter runs that code. VS Code can use a different interpreter from the one found first on the system PATH.
