# Python Setup Exercises

## Programs

- `q01_check_python_environment.py` displays the active Python version, interpreter location, implementation, and pip command.
- `q02_hello_world_and_input.py` reads input and prints a greeting.
- `q03_simple_calculator.py` reads two numbers and performs a selected arithmetic operation.

## Run a program

Open this folder in VS Code. Open Terminal, select the Python interpreter, then run a file with `python q01_check_python_environment.py`. Replace the filename to run another exercise.

For Python setup steps, see `python_and_vscode_setup.md`.
