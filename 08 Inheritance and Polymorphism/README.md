# 08 Inheritance and Polymorphism

## Syllabus focus

Extend a base class with derived classes and use a shared interface for related objects.

## Learning outcomes

- Identify a parent class and its subclasses.
- Reuse inherited attributes and methods.
- Call a parent implementation with `super()`.
- Explain method overriding and polymorphic behavior.

## Programs in this folder

Four Python files focus on class hierarchies. Start with `person_employee.py` for a person/employee relationship and `multilevel_inheritance.py` for a multilevel example. Related class exercises are also kept in their original subfolders here.
