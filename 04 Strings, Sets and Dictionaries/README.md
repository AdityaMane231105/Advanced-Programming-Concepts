# 04 Strings, Sets and Dictionaries

## Syllabus focus

Manipulate text and use sets and dictionaries to represent unique values and key/value data.

## Learning outcomes

- Use string indexing, slicing, iteration, and common transformation methods.
- Build frequency tables and look up values by dictionary key.
- Apply set operations such as union, intersection, and symmetric difference.
- Validate and normalize text inputs while accounting for case and punctuation.

## Programs in this folder

The 37 Python files cover anagrams, palindromes, character and word frequency, string transformations, set vocabulary exercises, and standalone validators. Examples include `Character Frequency.py`, `Vocabulary Analysis (Sets).py`, and `Email Validator.py`.

The validation files are standalone examples. This folder does not contain a Django login application; that syllabus topic is Experiment 12.
