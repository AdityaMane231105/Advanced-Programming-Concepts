# 01 Python Basics

## Syllabus focus

Practice the building blocks of Python: variables and data types, input and output, operators, expressions, decisions, and loops.

## Learning outcomes

- Read input, convert values, and display clear results.
- Use arithmetic, comparison, and Boolean operators.
- Write `if`/`elif`/`else` branches and `for`/`while` loops.
- Trace a short program and handle common numeric cases.

## Programs in this folder

The 42 Python files include data type demonstrations and short exercises for even/odd and prime numbers, number ranges, sums, digit operations, patterns, and simple decisions. Examples include `Data Types.py`, `Even and Odd.py`, `Check Prime.py`, and `Digit-Sum.py`.

Run an individual exercise with Python 3 and follow its prompts. The files are standalone examples unless they are inside a named subfolder.
