# 13 Python Mini Project

## Syllabus focus

Combine the course concepts in a small, coherent Python application with a clear purpose and separated responsibilities.

## Learning outcomes

- Turn a problem statement into features and a simple program structure.
- Organize related code into modules and packages.
- Use functions, collections, files, and classes where they fit the problem.
- Run the application, exercise its main paths, and document its use.

## Projects in this folder

The 114 Python files include multi-file examples for banking, e-commerce, college/student records, libraries, medical records, math utilities, recursion, text tools, and student management. Each project keeps its original subfolder structure and filenames.

Choose one project directory at a time. Some projects are alternative examples with similar themes; their files are retained as supplied and were not combined.
