# 12 Django Login and Regex Validation

## Syllabus focus

Create a Django login flow and validate user input with regular expressions where appropriate.

## Learning outcomes

- Recognize the role of Django projects, apps, URL routes, views, and templates.
- Connect a login form to Django’s authentication flow.
- Validate fields and present useful error messages.
- Use regular expressions for format checks, while keeping authentication separate from format validation.

## Repository coverage

No Django login application was present in the source repository. Standalone email, password, IP, and phone validation examples are in Experiment 04; they are not a Django implementation.
